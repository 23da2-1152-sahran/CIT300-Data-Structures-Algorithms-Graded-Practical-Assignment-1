# University Student Record and Campus Route Management System

## CIT300 - Data Structures and Algorithms

### Project Description

This project is a Java console-based University Student Record and Campus Route Management System.

The system manages student records and represents connections between university campus locations using different data structures.

## Data Structures Used

The project demonstrates the following data structures:

1. Linked List
2. Stack
3. Queue
4. Binary Search Tree (BST)
5. Hash Table
6. Graph

## Main Features

### Student Management
- Add Student Record
- Update Student Record
- Delete Student Record
- Display All Student Records

### Service Management
- Add Service Request to Queue
- Process Next Service Request

### Student Searching and Organization
- Display Students using BST
- Search Student using Hashing

### Campus Route Management
- Add Campus Location
- Remove Campus Location
- Add Campus Connection/Road
- Remove Campus Connection/Road
- Display Campus Connections
- Traverse Campus Locations using BFS/DFS
